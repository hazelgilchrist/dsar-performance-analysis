# DSAR Performance Analysis

A beginner SQL and data visualisation project exploring performance, SLA breaches and delay drivers within a synthetic DSAR dataset.

## About the project

I created this project while developing my SQL and data skills alongside my current role in data protection.

I wanted to take the concepts I had been learning and apply them to a subject I understand well, so I created a synthetic DSAR dataset and used it to explore operational performance and breach trends.

The project looks at questions such as:

- How does DSAR performance change over time?
- What are the most common causes of SLA breaches?
- Are there patterns in where delays occur?
- How can operational data be presented in a useful way for reporting and decision-making?

## Tools used

- SQL
- Google BigQuery
- Looker Studio

## What I did

I imported the dataset into BigQuery and used SQL to clean, query and analyse the data.

This included:
- cleaning inconsistent values
- analysing requests by received date
- identifying and grouping breach root causes
- exploring patterns in DSAR performance
- turning the results into visualisations in Looker Studio

## What I learned

This was my first project applying SQL to a dataset independently.

It helped me move beyond completing individual SQL exercises and understand how SQL can be used as part of a wider analytical process — from preparing data and asking questions through to presenting the results visually.

It also highlighted areas I want to develop further, particularly writing more complex queries and building scalable data models.
